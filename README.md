# mini-shop

uni-app + Vue 3 + TypeScript + script setup 基础工程。

## 快速开始

```bash
npm install
npm run dev:mp-weixin
```

## 可用脚本

- `npm run dev`：默认开发模式
- `npm run dev:h5`：启动 H5
- `npm run dev:h5:mock`：启动 H5（开启本地 mock）
- `npm run dev:wx`：启动微信小程序（快捷）
- `npm run dev:wx:mock`：启动微信小程序（开启本地 mock）
- `npm run dev:mp-weixin`：启动微信小程序
- `npm run build`：默认构建
- `npm run build:h5`：构建 H5
- `npm run build:h5:mock`：构建 H5（开启本地 mock）
- `npm run build:wx`：构建微信小程序（快捷）
- `npm run build:wx:mock`：构建微信小程序（开启本地 mock）
- `npm run build:mp-weixin`：构建微信小程序
- `npm run type-check`：类型检查
- `npm run lint`：代码检查
