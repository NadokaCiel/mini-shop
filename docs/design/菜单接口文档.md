# 菜单接口文档（门店一级分类版）

## 1. 业务前提

- 菜单仅支持**一级分类**（当前阶段不做二级分类）。
- 分类按**门店维度配置**。
- 当前仅有一家门店，但接口保持 `storeId` 入参，兼容后续多门店。
- 同一商品（SPU）允许出现在多个分类下（分类与商品为多对多关系）。

## 2. 数据关系约束

## 2.1 核心实体

- `store`：门店
- `menu_category`：菜单分类（一级）
- `spu`：商品主体
- `menu_category_spu_rel`：分类与商品关联关系（支持复用）

## 2.2 关系说明

- `store 1 - N menu_category`
- `menu_category N - N spu`（通过 `menu_category_spu_rel`）
- 一个 `spu` 可归属多个 `category`，每个分类内有独立排序与展示标签。

## 3. 统一返回约定

后端返回建议：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

字段命名：后端 `snake_case`，前端由 API 层自动转 `camelCase`。

---

## 4. 接口清单

1. `queryMenuCategoryList` 查询门店菜单分类
2. `queryMenuSpuListByCategory` 查询分类下商品列表
3. `queryMenuIndexData` 菜单页聚合接口（推荐）

---

## 5. 接口详情

## 5.1 queryMenuCategoryList

### 用途

- 获取某门店的一级分类导航。

### 请求

- `GET /menu/category/list?store_id=store_001`

### 请求参数

- `store_id`（必填，string）：门店ID

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "category_id": "cat_coffee",
      "category_name": "咖啡",
      "sort": 1,
      "status": "on"
    },
    {
      "category_id": "cat_dessert",
      "category_name": "甜品",
      "sort": 2,
      "status": "on"
    }
  ]
}
```

### 说明

- 仅返回一级分类。
- 建议按 `sort` 升序返回。
- `status=off` 的分类不返回给前端。

---

## 5.2 queryMenuSpuListByCategory

### 用途

- 获取某门店、某分类下的 SPU 列表。

### 请求

- `POST /menu/spu/list/by-category`

### 请求体

```json
{
  "store_id": "store_001",
  "category_id": "cat_coffee",
  "page_num": 1,
  "page_size": 20
}
```

### 请求参数说明

- `store_id`（必填）：门店ID
- `category_id`（必填）：分类ID
- `page_num`（选填，默认1）
- `page_size`（选填，默认20，建议上限50）

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "total": 2,
    "list": [
      {
        "spu_id": "spu_latte_vanilla",
        "title": "香草拿铁",
        "sub_title": "奶香顺滑",
        "base_price": 18,
        "cover_url": "https://cdn.xxx/spu_latte_vanilla.png",
        "has_sku": true,
        "status": "on",
        "menu_tags": ["hot", "recommend"]
      },
      {
        "spu_id": "spu_americano",
        "title": "美式咖啡",
        "sub_title": "清爽回甘",
        "base_price": 15,
        "cover_url": "https://cdn.xxx/spu_americano.png",
        "has_sku": true,
        "status": "on",
        "menu_tags": ["classic"]
      }
    ]
  }
}
```

### 说明

- 同一 `spu_id` 允许在多个分类下出现（通过关联表决定）。
- 分类内顺序按 `menu_category_spu_rel.sort` 返回。
- 商品下架或门店不可售时不返回。

---

## 5.3 queryMenuIndexData（推荐）

### 用途

- 菜单页首屏聚合：一次返回分类与默认分类商品，减少前端首屏请求次数。

### 请求

- `GET /menu/index?store_id=store_001`

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "store_id": "store_001",
    "categories": [
      { "category_id": "cat_coffee", "category_name": "咖啡", "sort": 1 },
      { "category_id": "cat_dessert", "category_name": "甜品", "sort": 2 }
    ],
    "default_category_id": "cat_coffee",
    "default_category_spu_list": [
      {
        "spu_id": "spu_latte_vanilla",
        "title": "香草拿铁",
        "base_price": 18,
        "has_sku": true
      }
    ]
  }
}
```

### 说明

- `default_category_id` 通常取排序第一分类。
- 切换分类后再调用 `queryMenuSpuListByCategory` 分页拉取。

---

## 6. 错误码建议（菜单域）

- `2101001`：门店不存在
- `2101002`：门店菜单未配置
- `2101003`：分类不存在或不属于该门店
- `2101004`：分类下暂无商品
- `2101005`：分页参数非法

---

## 7. 前端接入建议（当前 uni-app 项目）

- 建议模块：`src/api/modules/menu`
  - `types.ts`：分类、列表、聚合接口类型
  - `contracts.ts`：接口 path 与 schema
  - `http.ts`：`queryMenuCategoryList`、`queryMenuSpuListByCategory`、`queryMenuIndexData`
  - `index.ts`：导出 `getMenuHttp()`

调用示例（符合你当前返回包装）：

```ts
const [result] = await getMenuHttp().queryMenuIndexData({ storeId: 'store_001' })
if (!result.isOk) {
  return
}
const menuData = result.getData()
```

---

## 8. 当前阶段实现建议（仅一家门店）

- 前端默认携带固定 `storeId=store_001`（可放在配置项）。
- 后端仍保留 `store_id` 字段，避免后续多门店改造成本。
- 分类与商品关系务必通过关系表维护，不要把 `categoryId` 直接固化在 SPU 主表。
