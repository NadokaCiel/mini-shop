# 商品接口清单（菜单场景 / MVP）

## 1. 说明

- 面向模块：菜单、商品详情、购物车、结算前校验。
- 命名规则：
  - 后端接口字段：`snake_case`
  - 前端消费字段：`camelCase`（由 API 层自动转换）
- 返回封装：前端统一使用
  - `const [result, typeDeclaration] = await getProductHttp().xxx(...)`
  - `result.isOk / result.getMsg() / result.getData()`

## 2. 接口总览

1. `queryCategoryList` 分类列表
2. `querySpuList` SPU商品列表（菜单页）
3. `querySpuDetail` SPU详情（含SKU、属性组、小料）
4. `querySkuStock` SKU库存查询（可选）
5. `createCartItem` 加入购物车
6. `updateCartItem` 更新购物车项
7. `removeCartItem` 删除购物车项
8. `queryCart` 查询购物车
9. `validateCartForCheckout` 结算前校验

---

## 3. 详细接口定义（建议）

## 3.1 queryCategoryList

### 用途

- 菜单页左侧分类导航数据源。

### 请求

- `GET /product/category/list`

### 响应（后端snake）

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "category_id": "c001",
      "category_name": "咖啡",
      "sort": 1
    }
  ]
}
```

### 前端消费（camel）

- `categoryId`
- `categoryName`
- `sort`

---

## 3.2 querySpuList

### 用途

- 获取某分类SPU列表（菜单卡片）。

### 请求

- `POST /product/spu/list`

```json
{
  "category_id": "c001",
  "page_num": 1,
  "page_size": 20
}
```

### 响应要点

- 返回SPU维度数据，不展开完整SKU树。
- 关键字段：
  - `spu_id`
  - `title`
  - `sub_title`
  - `base_price`
  - `has_sku`
  - `cover_url`
  - `status`

---

## 3.3 querySpuDetail

### 用途

- 商品规格弹层数据源（核心接口）。

### 请求

- `GET /product/spu/detail?spu_id=xxx`

### 响应结构（建议）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "spu_id": "spu1001",
    "title": "香草拿铁",
    "base_price": 18,
    "sku_list": [
      { "sku_id": "sku_m", "sku_name": "中杯", "price_delta": 0, "stock_count": 99 },
      { "sku_id": "sku_l", "sku_name": "大杯", "price_delta": 3, "stock_count": 99 }
    ],
    "attribute_groups": [
      {
        "group_id": "g_temp",
        "group_name": "温度",
        "required": true,
        "multi_select": false,
        "items": [
          { "item_id": "hot", "item_name": "热", "price_delta": 0, "is_default": true },
          { "item_id": "ice", "item_name": "冰", "price_delta": 0, "is_default": false }
        ]
      }
    ],
    "available_toppings": [
      { "topping_id": "tp001", "name": "奶盖", "price_delta": 2, "status": "on" }
    ]
  }
}
```

---

## 3.4 querySkuStock（可选）

### 用途

- 规格变化时做库存实时检查（并发场景）。

### 请求

- `POST /product/sku/stock/query`

```json
{
  "sku_ids": ["sku_m", "sku_l"]
}
```

### 响应

- 返回 `sku_id -> stock_count` 映射。

---

## 3.5 createCartItem

### 用途

- 将当前选择配置加入购物车。

### 请求

- `POST /cart/item/create`

```json
{
  "spu_id": "spu1001",
  "sku_id": "sku_l",
  "quantity": 1,
  "selected_attribute_items": [
    { "group_id": "g_temp", "item_id": "hot" },
    { "group_id": "g_sugar", "item_id": "half" }
  ],
  "selected_topping_ids": ["tp001", "tp003"],
  "remark": "少冰"
}
```

### 响应

- 返回 `cart_item_id`、`cart_total_count`、`cart_total_amount`。

---

## 3.6 updateCartItem

### 用途

- 更新购物车项数量或配置。

### 请求

- `POST /cart/item/update`

```json
{
  "cart_item_id": "ci_10001",
  "quantity": 2
}
```

### 说明

- 若涉及规格变更，建议要求前端重新提交配置快照。

---

## 3.7 removeCartItem

### 用途

- 删除购物车项。

### 请求

- `POST /cart/item/remove`

```json
{
  "cart_item_ids": ["ci_10001", "ci_10002"]
}
```

---

## 3.8 queryCart

### 用途

- 购物车页拉取最新数据。

### 请求

- `GET /cart/query`

### 响应要点

- 按门店分组（可选）
- 购物项快照字段完整返回：
  - `spu_snapshot`
  - `sku_snapshot`
  - `selected_attributes`
  - `selected_toppings`
  - `unit_final_price`
  - `line_amount`

---

## 3.9 validateCartForCheckout

### 用途

- 结算前校验库存、营业状态、价格有效性。

### 请求

- `POST /cart/checkout/validate`

```json
{
  "cart_item_ids": ["ci_10001"],
  "delivery_type": "pickup"
}
```

### 响应

- `is_valid`
- `invalid_reasons[]`
- `price_diff_items[]`

---

## 4. 错误码建议（商品域）

- `2001001`：SPU不存在或已下架
- `2001002`：SKU不存在或不可售
- `2001003`：库存不足
- `2001004`：属性选择不完整
- `2001005`：小料不可用
- `2001006`：价格已变更，请刷新
- `2001007`：门店当前不可下单

---

## 5. 前端落地映射建议（当前项目）

- 新增/扩展目录：`src/api/modules/product`
  - `types.ts`：声明上述请求响应类型
  - `contracts.ts`：声明接口路径与复杂schema
  - `http.ts`：封装 `querySpuList/querySpuDetail/createCartItem...`
- 复杂结构建议落 JSON：
  - `spu-detail.response.schema.json`
  - `create-cart-item.request.schema.json`
  - `query-cart.response.schema.json`

---

## 6. 联调优先级

1. `queryCategoryList`
2. `querySpuList`
3. `querySpuDetail`
4. `createCartItem`
5. `queryCart`
6. `validateCartForCheckout`

先保证菜单加购主链路，再补库存与异常精细化策略。
