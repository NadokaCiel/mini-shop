# 商品数据模型概念文档（SPU / SKU / 属性 / 小料）

## 1. 目标与范围

- 统一小程序商品域的核心概念，避免菜单、购物车、订单三端口径不一致。
- 适用于初期 MVP：咖啡、非咖、小料、点心、周边。
- 对齐后端管理逻辑：属性与加价策略由后台统一维护。

## 2. 核心概念定义

## 2.1 SPU（Standard Product Unit）

- 最上层商品概念，是**菜单列表项最小单位**。
- 示例：`香草拿铁`、`可颂`、`马克杯`、`奶盖`（小料也可作为SPU管理）。
- SPU可分为两类：
  - **含规格SPU**：存在多个 SKU（如中杯/大杯）。
  - **无规格SPU**：只有一个默认 SKU（如点心、周边、小料单品）。

## 2.2 SKU（Stock Keeping Unit）

- SPU下的可售卖规格单元。
- 示例：`香草拿铁-中杯`、`香草拿铁-大杯`。
- SKU承载库存、售卖状态、规格加价信息。

## 2.3 底价与加价规则

- **SPU底价**：该商品的基础价格（菜单展示默认价格锚点）。
- **SKU加价**：相对 SPU 底价的增量价格（如大杯 +3 元）。
- **小料加价**：每个小料独立加价，多选累加。
- 最终成交价建议计算：
  - `成交价 = spu底价 + sku加价 + 属性加价合计 + 小料加价合计`

## 2.4 小料（Topping）

- 在 SPU 维度维护“可用小料列表”。
- 选择规则：多选，可不选。
- 小料本身可复用（同一小料可挂载到多个SPU）。

## 2.5 属性（Attribute）

- SPU下维护属性组，如 `温度`、`甜度`、`做法`。
- 统一视为“属性”概念，由后台统一管理。
- 属性项保留加价字段（可为 0）。
- 典型规则：
  - 单选属性组：温度、做法。
  - 可选属性组：甜度（也可强制默认值）。

## 3. 实体关系模型

- `SPU 1 - N SKU`
- `SPU 1 - N 属性组`
- `属性组 1 - N 属性项`
- `SPU N - N 小料`（可通过关联表实现）

建议关系：

- `spu`：商品主体
- `sku`：规格
- `spu_attribute_group`：属性组
- `spu_attribute_item`：属性项
- `spu_topping_rel`：SPU与小料关系
- `topping`：小料定义

## 4. 字段建议（概念层）

## 4.1 SPU字段

- `spuId`
- `spuCode`
- `title`
- `subTitle`
- `categoryId`
- `basePrice`（底价）
- `coverUrl`
- `status`（on/off）
- `hasSku`
- `defaultSkuId`
- `availableToppingIds[]`

## 4.2 SKU字段

- `skuId`
- `spuId`
- `skuName`（中杯/大杯）
- `priceDelta`（相对SPU底价加价）
- `stockCount`
- `status`

## 4.3 属性组字段

- `groupId`
- `spuId`
- `groupName`（温度/甜度/做法）
- `required`（是否必选）
- `multiSelect`（是否多选）
- `sort`

## 4.4 属性项字段

- `itemId`
- `groupId`
- `itemName`（热/冰/少糖等）
- `priceDelta`
- `isDefault`
- `sort`

## 4.5 小料字段

- `toppingId`
- `name`
- `priceDelta`
- `status`
- `sort`

## 5. 菜单展示口径建议

- 菜单卡片价格展示：优先显示 SPU 底价（如 `¥18起`）。
- 若 SPU 无SKU且无可变加价项，可直接展示固定价。
- 商品详情弹层中展示：
  - SPU基础信息
  - SKU选项
  - 属性组选项
  - 可选小料
  - 实时总价

## 6. 购物车快照建议

下单后价格和配置要可追溯，购物车/订单必须保存快照：

- `spuSnapshot`
- `skuSnapshot`
- `selectedAttributes[]`（含价格）
- `selectedToppings[]`（含价格）
- `unitFinalPrice`
- `quantity`
- `lineAmount`

## 7. 前后端命名与转换约定

- 后端：下划线命名（`spu_id`、`price_delta`）。
- 前端：小驼峰命名（`spuId`、`priceDelta`）。
- 在当前项目中由 API core 统一完成：
  - 请求参数：camel -> snake
  - 响应数据：snake -> camel

## 8. 价格计算参考

```text
spuBasePrice = 18
skuDelta(大杯) = +3
attrDelta(燕麦奶做法) = +2
toppingDelta(奶盖 + 椰果) = +2 +1

singlePrice = 18 + 3 + 2 + 3 = 26
lineAmount = singlePrice * quantity
```

## 9. 初期实现建议（MVP）

- 优先支持：
  - 单SKU和多SKU两种SPU
  - 单选属性组（温度/做法）
  - 小料多选
  - 实时价格联动
- 预留但可后置：
  - 属性依赖（某些属性互斥）
  - 按门店动态库存与动态加价
  - 组合套餐（Bundle）
