# 咖啡小程序原型设计（核心设计）

## 1. 项目定位

- **产品目标**：打造一个兼具效率与社区氛围的咖啡小程序，覆盖「浏览-选品-下单-履约-复购」闭环。
- **用户画像**：
  - 城市年轻用户（18-35），偏好便捷下单与高颜值体验。
  - 喜爱社区互动与个性表达的福瑞文化圈层用户。
- **设计关键词**：年轻、新潮、友好、温暖、轻社交、可分享。

## 2. 信息架构（IA）

### 2.1 一级导航（Tab）

- 首页
- 菜单
- 订单
- 我的

### 2.2 二级业务页面（包括但不限于）

- 商品规格详情
- 购物车
- 结算单
- 地址管理
- 优惠券选择
- 订单详情
- 支付结果
- 会员权益/积分中心

## 3. 核心界面原型说明

## 3.1 首页

### 页面目标

- 承载品牌氛围、营销触达、活动引导和快捷复购入口。

### 结构建议

- 顶部：门店与自提/外送切换、搜索入口。
- 中部：
  - 轮播 Banner（新品、联名、限时活动）。
  - 快捷分类（拿铁、手冲、冷萃、甜品、周边）。
  - 社区推荐卡片（UGC 热门打卡）。
- 底部：
  - 猜你喜欢（个性化推荐）。
  - 最近常点（一键复购）。

### 关键交互

- 下拉刷新活动与推荐。
- 卡片点击进入商品规格详情。
- 社区内容支持点赞/收藏/分享。

## 3.2 菜单

### 页面目标

- 高效完成点单，降低决策成本。

### 结构建议

- 左侧：分类导航（热销、新品、咖啡、非咖、甜品、周边）。
- 右侧：商品列表（图片、名称、标签、价格、加号按钮）。
- 顶部筛选：口味、温度、甜度、价格区间。

### 关键交互

- 点击商品进入规格弹层或详情页。
- 快速加购支持数量步进。
- 滑动时分类自动联动高亮。

## 3.3 订单

### 页面目标

- 可视化订单状态，减少咨询与售后成本。

### 结构建议

- 状态标签页：全部、待支付、制作中、待取餐、已完成、已取消。
- 订单卡片：门店、商品摘要、金额、状态、时间。
- 操作按钮：去支付、再来一单、申请售后、查看详情。

### 关键交互

- 状态轮询与手动刷新。
- 支付超时提醒。
- 一键复购跳转菜单并回填购物车。

## 3.4 我的

### 页面目标

- 建立用户资产与社区身份，提高留存与复购。

### 结构建议

- 用户卡片：头像、昵称、会员等级、成长值。
- 权益入口：优惠券、积分、礼品卡、订阅权益。
- 服务入口：地址、发票、客服、帮助反馈、设置。
- 社区入口：我的收藏、我的发布、勋章墙（福瑞主题）。

### 关键交互

- 登录后信息渐进式加载。
- 权益卡片可视化进度。
- 社区身份徽章支持分享。

## 4. 业务流程组件/页面设计

## 4.1 商品规格详情

- **展示内容**：商品图、简介、规格、温度、杯型、甜度、加料、备注。
- **交互规则**：
  - 必选项校验（未选不可加入购物车）。
  - 动态价格联动（加料/升级杯型实时更新）。
  - 支持收藏与分享。

## 4.2 购物车

- **展示内容**：按门店分组商品、数量控制、优惠明细、预计到手价。
- **交互规则**：
  - 勾选结算、批量删除、失效商品提醒。
  - 配送方式切换（自提/外送）影响费用与时间。
  - 满减与券后价实时计算。

## 4.3 结算单

- **展示内容**：商品清单、收货/自提信息、优惠券、积分抵扣、支付方式、应付金额。
- **交互规则**：
  - 提交前二次校验库存与门店营业状态。
  - 支付失败可回退重试。
  - 风险订单弹窗提醒（地址异常、库存不足）。

## 4.4 订单详情（建议）

- 状态时间轴（下单-制作-完成）。
- 核销码/取餐码突出展示。
- 售后与客服入口直达。

## 5. 视觉风格：年轻新潮 + 福瑞社区感

## 5.1 色彩方案

- **品牌主色**：`#FF7A45`（活力橙，传递热情与食欲）
- **辅助色**：`#7C4DFF`（潮流紫，增强次元与个性表达）
- **点缀色**：`#00C2A8`（清新薄荷绿，用于状态与标签）
- **中性色**：
  - 背景：`#FFF8F2`（暖奶油）
  - 主文字：`#2C2C2C`
  - 次文字：`#6F6F6F`
  - 分割线：`#EAEAEA`

## 5.2 组件风格规范

- 圆角体系：卡片 `16rpx`，按钮 `999rpx`（胶囊按钮）。
- 阴影体系：轻阴影，避免厚重拟物。
- 图标体系：线性+圆润，局部福瑞耳朵/尾巴元素可作为主题贴纸。
- 插画风格：高饱和+软萌轮廓，强化社区氛围与情绪价值。

## 5.3 字体与层级

- 标题：32-36rpx，半粗。
- 正文：26-28rpx。
- 辅助说明：22-24rpx。
- 金额与核心操作采用更高对比与字重。

## 5.4 动效规范

- 按钮点击：80-120ms 缩放反馈。
- 加购动效：商品飞入购物车轨迹动画（轻量）。
- 页面切换：位移+淡入，时长 180-220ms。

## 6. 社区化体验（福瑞文化贴近策略）

- 主题活动：每月福瑞主题徽章与联名杯套活动。
- UGC 打卡：发布饮品照片、门店签到、口味测评。
- 社交激励：点赞/评论/收藏与积分联动。
- 身份表达：个人主页展示“风格标签”“偏好口味”“勋章”。

- **原型工具建议**：Figma / MasterGo。
- **页面优先级**：
  1. 首页
  2. 菜单 + 商品规格详情
  3. 购物车 + 结算单
  4. 订单 + 我的
- **交付物清单**：
  - 低保真流程图
  - 中保真页面流
  - 高保真关键页（首页、菜单、结算、我的）
